# Test images

  ([File:Abraham Lincoln O-77 matte collodion print.jpg](https://commons.wikimedia.org/wiki/File:Abraham_Lincoln_O-77_matte_collodion_print.jpg)), public domain.
- `group_bw.jpg` — Fifth Solvay Conference, photographed by Benjamin Couprie, 1927
  ([File:Solvay conference 1927.jpg](https://commons.wikimedia.org/wiki/File:Solvay_conference_1927.jpg)), public domain.

They are used by the photo-restoration tests that need real faces
(`tests/test_restoration_models.py`, skipped unless the models are installed).
